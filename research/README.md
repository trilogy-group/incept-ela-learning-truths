# Research

Every run that added to the records, stored the same way: see [schema/RUNS.md](../schema/RUNS.md) for the layout and
the steps (`scripts/run.py`), and [schema/run.schema.json](../schema/run.schema.json) for `run.json`. A record's
`found_in` names the runs it came from; `python3 scripts/run.py status` lists them all.
